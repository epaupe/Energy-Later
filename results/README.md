# Results Folder

This directory contains the output files generated by the BESS dispatch optimization model.  
Each results file is an `.xlsx` table summarizing **yearly operational revenues**, split by market, under different price-volatility assumptions and market-entry scenarios.

---

## 1. Content of Each Results File

Each `yearly_results_*.xlsx` file contains:
- **Total yearly profit (cashflow)** of the BESS
- **Revenue decomposition** across:
  - Day-Ahead (DA) energy market
  - Frequency Containment Reserve (FCR)
  - Automatic Frequency Restoration Reserve (aFRR)

These values are computed using the receding-horizon dispatch model with 72-hour look-ahead and yearly battery degradation assumptions.

---

## 2. Market Entry Scenarios

Two market-entry years are considered:

### **Scenario A — Entry in 2024**
- Revenues computed for **15 consecutive years**, from 2024 to 2040.

### **Scenario B — Entry in 2029**
- Revenues computed for **15 consecutive years**, from 2029 to 2044.

These scenarios reflect different investment timings and capture the effect of market evolution across time.

---

## 3. Day-Ahead Price Volatility Assumptions

For each market entry scenario, the optimization is run **three times**, each with a different assumption for the year-to-year evolution of DA price volatility:

1. **`volatility_1`**  
   → Annual volatility **remains constant** (baseline).

2. **`volatility_099`**  
   → Annual volatility **decreases by 1%**.

3. **`volatility_101`**  
   → Annual volatility **increases by 1%** relative to the previous year.

The DA price mean is held constant across years; only volatility evolves according to the selected scenario.  
These synthetic forecasts are generated using a stochastic model implemented in  
**`DA_volatility_forecasts.py`**.
